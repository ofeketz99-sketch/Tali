# Download Tali

אתר נחיתה סטטי ועצמאי, המבוסס על שפת העיצוב של ערכת הנושא הבהירה `warm` ב-Tali.

- אתר תדמית רספונסיבי בעברית; ללא JavaScript, תלות ב-Electron או שירות חיצוני.
- ההצצה לממשק היא המחשה עיצובית ולא צילום מסך של התוכנה.
- אין הורדה פעילה, הרשמה, אנליטיקה, API או קובץ התקנה. כפתור ההורדה מושבת.
- הלוגו הוא אותו נכס כמו באפליקציה, וכל קובצי האתר נמצאים ב-`website/`.

## פיתוח מקומי

פתיחת `website/index.html` בדפדפן, או הרצה משורש המאגר:

```sh
python -m http.server 8080 --directory website
```

ואז http://localhost:8080 .

## פרסום עתידי

אפשר לחבר את המאגר הפרטי ל-Netlify ולהגדיר Publish directory כ-`website`, ללא Build command. הקובץ `netlify.toml` בשורש כבר מגדיר זאת. אפשר לפרסם גם בכל שירות אחסון סטטי אחר.

הוספת האתר ל-GitHub **אינה מפרסמת אותו אוטומטית באינטרנט**. אין לשנות את המאגר הפרטי לציבורי כדי לפרסם אותו. בהמשך יש להוסיף בנפרד קבצים חתומים, מנגנון הפצה/עדכונים וקישור הורדה.
