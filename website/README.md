# Download TALI

אתר הורדה מינימליסטי סטטי, במסך אחד, בשפת העיצוב הבהירה של TALI. כולל רק סמל, שם האפליקציה וכפתור הורדה בולט. אין ניווט, פירוט יכולות, אזורי שיווק או גלילה.

## פיתוח מקומי

- כל קובצי האתר נמצאים ב-`website/`, והלוגו המקורי ב-`website/assets/logo.png`.
- אין צורך ב-JavaScript או בבניית Electron כדי להציג את האתר.
- פתחו `website/index.html` בדפדפן או הריצו משורש המאגר: `python -m http.server 8080 --directory website`.

## ענפי Git ו-Netlify

- `main`: ענף האתר הראשי; Netlify מפרסם אותו בכתובת הרגילה.
- `dev`: ענף הפיתוח (אותיות קטנות, בדומה ל-RONNY); Netlify מפרסם אותו אוטומטית בכתובת נפרדת `dev--<site-name>.netlify.app`.
- מפתחים ושומרים שינויים ב-`dev`, וממזגים ל-`main` רק כאשר הגרסה מוכנה לפרסום.
- הגדרת Netlify: Production branch = `main`, Branch deploys = `dev` בלבד. אפשר לכבות Deploy Previews כדי להימנע מבניות נוספות שאינן נדרשות.
- אין פקודת `ignore` ב-`netlify.toml` שחוסמת את פריסות `dev`. כל push ל-`dev` עשוי להפעיל פריסה ולצרוך קרדיטים ב-Netlify. פיתוח מקומי אינו מחייב פריסה.
- ענף `DEV` (באותיות גדולות) הוא ענף ישן שנוצר בתחילה. העבודה החדשה באתר צריכה להתבצע ב-`dev` בלבד.

## קובץ ההתקנה

כפתור ההורדה מעוצב אך **מושבת בכוונה**, עם הודעה: "ההורדה עדיין לא זמינה". הקובץ הקיים ב-GitHub Releases נמצא במאגר פרטי ואינו מתאים כרגע להפצה ציבורית לחברים שאין להם גישה אליו.

כשיהיה קובץ התקנה בכתובת ציבורית מאומתת, מחליפים את `button.download-button` ב-`website/index.html` בקישור `a.download-button` עם `href` תקין, ומסירים את הודעת אי-הזמינות. אין צורך במנגנון הורדה מורכב.
