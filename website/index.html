7.5

TALI-DEV: גרסת הפיתוח נפתחת גם עם Smart App Control

14.11.2026
  • הבעיה: Smart App Control של Windows 11 חסם את Tali.exe של הפיתוח, בלי אפשרות "הפעל בכל זאת".
  • הפתרון, TALI-DEV: npm run make-exe בונה עכשיו את התיקייה TALI-DEV ליד המאגר, עם TALI-DEV.exe: עותק זהה בדיוק ל־electron.exe (רק השם שונה, בלי rcedit).
  • השם TALI-DEV: כשהאפליקציה נפתחת מ־TALI-DEV.exe, החלון, שורת המשימות ושורת הכותרת מציגים "TALI-DEV" (APP_TITLE ב־main.js, לפי שם הקובץ).
  • העדכון בפתיחה ובסגירה לא השתנה: אותו משגר (launcher/) בלי שום שינוי, ממשיך למשוך את desktop-dev מ־GitHub.
