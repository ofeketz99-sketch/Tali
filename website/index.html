שמירה בטוחה וממשק שקט יותר

16.11.2026
  • שמירה עמידה לקריסה: כל שמירה כותבת קודם עותק מלא ומסונכרן לדיסק בקובץ נסתר ליד המסמך (.שם.md.tali-saving), ורק אחר כך את המסמך עצמו.
  • שמירה שנכשלה מודיעה בבירור: במקום טקסט בשורת המצב בלבד, מופיעה הודעה בפינה עם כפתור „ניסיון חוזר”.
  • חיווי שמירה שקט: בזמן הקלדה רק הנקודה מסמנת שיש שינוי.
  • אישור בציור בעיצוב של Tali: ניקוי הציור וסגירה בלי שמירה שואלים בחלון של האפליקציה, בעברית ובכיוון הנכון, ולא בחלון confirm() של המערכת.

עדכון עצמי עמיד יותר

16.11.2026
  • ניסיון חוזר כש־Windows נועל את Git לרגע: אם git fetch נכשל ב־Permission denied בזמן כתיבה ל־.git/objects, המשגר ממתין ומנסה שוב עד שלוש פעמים.
  • לא נשארים על גרסה ישנה בגלל חסימה רגעית: התקלה שאירעה בפועל בעדכון מ־9.0 ל־9.5 מזוהה עכשיו במדויק, נרשמת ביומן ומקבלת התאוששות אוטומטית במקום המשך מיידי עם העותק הישן.
9.5

עריכה חלקה בחלון ובמסמך

16.11.2026
  • סרגל מצומצם במצב חלון: כש־Tali אינו מוגדל ואינו במסך מלא, קבוצות הכלים המשניות עוברות אוטומטית לתפריט „עוד כלים”.
  • Backspace כמו ב־Word: בשורה ריקה ממורכזת, Backspace ראשון משנה את היישור לימין.
  • יישור נשמר: יישור מפורש של פסקאות וכותרות נשמר כ־HTML תקני בתוך Markdown, ולכן טקסט ממורכז אינו קופץ לימין אחרי סגירה ופתיחה.
  • כותרת מסמך מעוצבת: בהגדרות „כתיבה ודף” אפשר לבחור גודל 20–64px (גם גדול מ־H1) ואחד מארבעה סגנונות: נקי, מודגש, קו צבע או תווית.
